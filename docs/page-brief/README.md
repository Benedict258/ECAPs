# ECAPs page brief

Inputs used to build the project page in `site/` (ecaps.benedictisaac.dev).

- `BUILD_SPEC.md`: rules, requirements and acceptance checklist.
- `PAGE_CONTENT.md`: final page copy (source of truth for text).
- `UIUX_BRIEF.md`: design reference.
- `COMPONENTS.md`: component inventory.
- `design-reference/index.html`: the original Claude Design file, kept for comparison. The page that ships is `site/src/index.html`.

`screenshots_local/` holds the design screenshots (large, git-ignored).
